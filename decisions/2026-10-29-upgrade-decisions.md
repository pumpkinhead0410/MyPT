# TL;DR

- 정체성 — MyPT는 하루 1~2회 접속해 일정·운동·식단·신체 지표의 추이를 기록하고 계획을 세우는 개인용 피트니스 플래닝 대시보드입니다.
- 기술 스택 — 유지보수성과 타입 안전성을 위해 단일 HTML 구조에서 Vite + React + TypeScript + Tailwind CSS 기반 PWA로 전환합니다.
- 영속성 — `localStorage` 자동 저장, 일자별 달성 히스토리(캘린더 히트맵), JSON 백업·복원 기능을 함께 도입합니다.
- 핵심 개편 — Tab 2의 기존 휴식 타이머와 세트별 세부 로깅을 기각하고, 루틴 카드 내 '대표 중량(kg)×횟수' 1줄 갱신과 종목별 중량·1RM 추이 차트를 채택했습니다.
- 보관 — 이 결정 기록과 [상세 작업계획](UPGRADE-PLAN.md), [재개 체크포인트](../.audit/implementation.todo.md)를 MyPT 내부에 보관하여 다음 세션부터 단독 워크스페이스 작업을 지원합니다.

- 참고 — 모바일·데스크톱 홈 화면 추가 및 오프라인 실행을 위한 PWA(Web App Manifest) 설정을 공통 요구사항으로 채택했습니다.

## 탭별 채택 및 기각 사항

### Tab 1: 저녁 일정 & 스케줄러
- 근거 — 3단계 검토에서 실시간 현재 시각 표시와 평일·주말 프로파일 분리를 채택했습니다.
- 참고 — 24시간 원형 다이얼과 13시간 선형 타임라인 바에 현재 시각(Now) 바늘·핀을 표시하고 현재 진행 중인 루틴 블록을 자동 포커스합니다.
- 참고 — 평일(출퇴근 포함)과 주말·휴일 스케줄 프로파일을 분리 저장하여 상황에 맞게 전환합니다.

### Tab 2: 운동 프로그램 & 추이 추적
- 근거 — 3~4단계 검토에서 사용자는 구체적인 세트별 실시간 기록보다 거시적 추이 추적을 원하며, 기존에 있던 세트 간 휴식 타이머를 삭제하도록 지시했습니다.
- 참고 — 요일 구성을 월~일(7일)로 확장하고 접속 시 오늘 요일을 자동 선택하며, 요일별 운동 종목·세트·유산소 프로토콜의 자유 편집(추가·수정·삭제·순서 변경)을 지원합니다.
- 참고 — Tab 1의 운동 시간 프리셋(60/80/100/120분) 변경 시 Tab 2의 운동 볼륨(권장 세트 수·유산소 시간)이 연동되도록 구성합니다.
- 참고 — 각 루틴 카드 내에 '대표 중량(kg)×횟수' 1줄 갱신 입력란을 두고, 중량 증량 시에만 간편하게 갱신하여 하단 '종목별 중량/추정 1RM 추이 차트'와 연동합니다.
- 기각 — 번핏·Hevy 스타일의 세트별 개별 kg·reps 상세 입력과 기존 세트 간 휴식 타이머(및 유산소 실전 인터벌 타이머)는 프로젝트 목적에 부합하지 않아 기각했습니다.
- 기각 — 루틴 영역과 중량 추이 테이블을 완전히 별도 패널로 분리하는 안보다 루틴 카드 내 1줄 갱신 + 하단 추이 차트 연동 안을 최종 선택했습니다.

### Tab 3: 식단 & 재고 관리
- 근거 — 3단계 검토에서 저녁 세트 다중 재고 연동과 식단 항목 자유 편집을 채택하고 수분 섭취 트래커는 제외하도록 지시했습니다.
